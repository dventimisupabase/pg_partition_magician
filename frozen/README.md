# Frozen artifacts

Point-in-time records, kept for history and not maintained against the code. Each one describes
the system (or, in one case, PostgreSQL partitioning in general) as it stood when written, not as
it works today. For that, start with [the user guide](../docs/guide.md) and
[the reference](../docs/reference.md) instead.

None of this is required reading, and nothing here is linked from the living documentation --
`scripts/check_living_docs.sh` enforces both directions: every file below must carry the "Frozen
artifact" banner you'll see at its top, and no living document may link to one of them. It exists
so a design decision, a measurement, or a plan can be traced back to when and why it was made,
without a newcomer (human or AI) having to sort the current picture from the historical one
themselves.
